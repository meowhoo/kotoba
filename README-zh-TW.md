# Kotoba

> 🎌 多國語言閱讀與學習工具

---

## 🎯 這是什麼？

**Kotoba** 是一款多國語言學習工具。支援多國語言的文字辨識，搭配 AI 翻譯與智慧單字卡系統，讓您輕鬆閱讀外文書籍、累積詞彙，打造個人化的語言學習環境。

**適合誰使用？**
- 📚 語言學習者，想累積詞彙、建立個人化單字庫
- 📖 需要 AI 翻譯輔助來閱讀外文書籍
- 💬 想將書籍內容翻譯成任何你需要的語言

---

## ✨ 主要功能

### 🔍 多語言 OCR 辨識
- 支援多國語言文字辨識
- 自動處理多欄排版（左右兩欄、雜誌排版）
- **排除框功能**：精確過濾頁碼、頁眉等干擾區域，徹底解決傳統 OCR 無法處理的邊角問題

### 🤖 多 LLM 翻譯
- 整合 OpenAI、Claude、Gemini、Grok 多種 AI 服務
- 可自訂翻譯風格、角色語氣與名詞對照表
- 每本書獨立設定，翻譯更貼近需求

### 📖 智慧閱讀模式
- **Image 模式**：顯示原圖，滑鼠移到單字上查看單字卡
- **Image+TL 模式**：左圖右譯，對照理解
- **Text 模式**：OCR 文字 + 單字列表，方便選取文字新增單字卡
- 中日文自動直排顯示，閱讀更自然
- 閱讀進度自動記錄，下次開啟從上次位置繼續

### 💬 AI 單字卡系統
- 透過 LLM 自動標註發音、翻譯與例句
- 支援跨書籍搜尋與篩選
- 匯出 Anki 卡牌，方便在 Anki 中複習

### 🎨 完整主題與多語言界面
- Light / Dark / 跟隨系統 三種主題
- 繁體中文 / English 雙語界面
- 無需安裝，解壓縮即可使用

## 🚀 如何使用

### 步驟 1：下載與安裝

**兩種安裝方式任選：**

#### 方式 A：安裝版（推薦）
1. 下載 `Kotoba-0.1.0-win-x64.exe`
2. 雙擊執行安裝程式
3. 選擇安裝位置，完成後自動啟動
4. 開始功能表會建立捷徑

#### 方式 B：便攜版
1. 下載 `Kotoba-0.1.0-win-x64.zip`
2. 解壓縮到任意資料夾（或 USB 隨身碟）
3. 雙擊 `Kotoba.exe` 啟動（無需安裝）

**系統需求**：Windows 10/11（64 位元）、4GB 記憶體、2GB 硬碟空間

### 步驟 2：取得 Google Vision API 金鑰（必要）

> 這是用來辨識書頁文字的服務，需要自己申請（免費額度：每月 1,000 張圖片）

1. 前往 [Google Cloud Console](https://console.cloud.google.com/)
2. 建立新專案或選擇既有專案
3. **啟用付費帳戶**（必須，即使使用免費額度也需要設定信用卡）
4. 啟用「Cloud Vision API」
5. 建立服務帳戶並下載 JSON 金鑰檔案
6. 在 Kotoba 的「系統設定」中選擇金鑰檔案

### 步驟 3：設定 AI 翻譯（選用）

如果需要翻譯功能，可取得以下任一服務的 API 金鑰：

- **OpenAI**（GPT-4 / GPT-3.5）
- **Anthropic Claude**（Sonnet / Haiku）
- **Google Gemini**（Gemini Pro）
- **xAI Grok**

在「系統設定」→「AI 設定」中填入金鑰即可使用。

## ❓ 常見問題

### Q: 首次執行時 Windows 出現安全警告怎麼辦？

這是正常現象，因為軟體未經 Microsoft 程式碼簽章認證。請依照系統版本處理：

**Windows 10 / 11 - SmartScreen 警告**
1. 出現「Windows 已保護您的電腦」或「Microsoft Defender SmartScreen 已封鎖無法識別的應用程式」
2. 點擊「更多資訊」（More info）
3. 點擊「仍要執行」（Run anyway）

**Windows 11 - Smart App Control（較嚴格）**

如果無法透過「仍要執行」繞過，表示啟用了 Smart App Control：
1. 開啟「設定」（Windows + I）
2. 前往「隱私權與安全性」→「Windows 安全性」→「應用程式與瀏覽器控制」
3. 點擊「Smart App Control 設定」
4. 選擇「關閉」（注意：關閉後需重設 Windows 才能重新開啟）

**替代方案：解除封鎖檔案**
1. 在 `Kotoba.exe` 上按右鍵 → 內容
2. 在「一般」分頁底部勾選「解除封鎖」（Unblock）
3. 按「套用」→「確定」

### Q: 完全免費嗎？

**A**: 軟體本身免費，但需要自行申請 Google Vision API（免費額度：每月 1,000 張圖片）。AI 翻譯功能需付費 API 金鑰（選用）。

### Q: 可以離線使用嗎？

**A**: 文字辨識（OCR）和 AI 翻譯需要網路連線。書庫管理、閱讀、單字卡功能可離線使用。

### Q: 如果我無法使用快捷鍵截圖怎麼辦？

**A**: 可以使用拖曳上傳功能。先用其他截圖工具（如 Windows 內建的剪取工具）截取書頁，再拖曳圖片到 Kotoba 的抓圖頁面即可。

### Q: 排除框有什麼用？

**A**: 書籍頁面的邊角經常有頁碼、頁眉、頁尾等干擾文字，這些區域是傳統 OCR 工具的噩夢——它們會混入正文，打亂閱讀順序，甚至造成翻譯錯誤。排除框功能讓您可以精確標記這些不需要辨識的區域，系統會在 OCR 時自動跳過，徹底解決這個問題。
